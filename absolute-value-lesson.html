📌 正数的绝对值是它本身：|+7| = 7
📌 负数的绝对值是它的相反数：|−7| = −(−7) = 7
📌 0 的绝对值是 0：|0| = 0
三种情况合起来，绝对值永远 ≥ 0（这叫"非负性"），而且 |a| = |−a|

解方程 |x| = 3：必须分情况！

绝对值是"距离"，可它不告诉你方向：在 0 左边还是右边？不知道 → 就分两种情况讨论。

化简：| a + 1 | + | a − 2 |

a 是什么数不知道，括号里的正负没法确定 → 先找零点，再分段讨论。 拖动蓝点或滑杆，看看三段里各发生了什么。

a = 0
① a < −1|a+1| = −(a+1)，|a−2| = −(a−2)原式 = 1 − 2a
② −1 ≤ a ≤ 2|a+1| = a+1，|a−2| = −(a−2)原式 = 3
③ a > 2|a+1| = a+1，|a−2| = a−2原式 = 2a − 1

✨ 三段在交界 a = −1、a = 2 处结果都是 3，刚好接上 —— 说明分段没有漏掉任何情况。

一页记住绝对值 📋

📏 定义：|a| 就是数轴上 a 到原点的距离
🧮 法则：正数 → 本身；负数 → 相反数；0 → 0
🛡 非负性：|a| ≥ 0；且 |a| = |−a|（对称）
⚖️ 比大小：两个负数，绝对值大的反而小
📍 推广：|x − a| 是 x 到 a 的距离（a 换成谁都可以）
🔀 分类讨论四步：① 定标准（括号里 ≥ 0 还是 < 0）→ ② 分情况/找零点分段 → ③ 每段解到底 → ④ 合并答案、检验

📝 课后挑战：① 化简 |a − 3| + |a + 1|（学第 ⑧ 幕找零点）；② 若 |a − 1| + |b + 2| = 0，求 a、b（学第 ④ 幕非负性）；③ 数轴上到 3 和 −1 距离相等的点是多少？（画画数轴）
